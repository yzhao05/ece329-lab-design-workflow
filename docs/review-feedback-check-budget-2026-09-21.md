# 经验检查预算与双语界面复审

本次审阅覆盖经验提炼配置、实际请求参数、检查结果校验、用量及诊断存储、跨服务商回退、重试上限、维护者阅读视图与中英文切换，并运行项目全量回归。没有修改线上数据或调用付费模型。

## 核对结果

- Guided 与 EMVR 共用 `ModelExperienceExtractor` / `FeedbackService`。检查强度独立于草案和 DeepSeek 模型预设，默认 `none`；检查上限默认 8192。实际调用及用量记录使用相同参数。
- 自定义检查上限仍被遵守，不会被 DeepSeek 适配器的默认预算抬高。显式设置较低额度的旧部署需要更新环境变量，代码不会覆盖已有配置。
- 截断结果仍被拒绝，不保存为可用经验。检查失败的草案不会绕过 Schema、证据引用或正反例校验。每次分析最多两次调用，没有递归修复。
- 网络故障的跨服务商回退和手动重试共享持久化的十次上限；输出截断不会触发自动回退。新增回归覆盖两种模式、两种服务商连续检查截断至第十次，并验证失败用量被记录、之后不能重试。
- 维护者反馈正文、对话、提示及分析的译文仅用于显示；原始 JSON、下载数据和审阅输入不变。更新了一份仍断言英文界面必须保留中文对话的旧浏览器验收脚本。
- 页面本地资源引用完整；Python 编译、前端脚本语法、Git 差异检查通过。

## 验证

- 项目全量后端回归：1506 passed、212 subtests passed（330.27 秒）。全量运行后补充的 4 个重试上限场景已在下述专项测试集中单独运行通过；生产代码未在全量运行期间改变。
- 前端单元测试：144 项通过。
- 新增的完整反馈流程回归所在测试集：27 项通过，包含 4 个“连续检查截断、手动重试至上限”的新场景。
- 真实浏览器使用模拟 API：独立折叠、刷新和切换语言后的草稿保留、原始 JSON 复制下载、图片预览、窄屏布局，以及两种模式的双向翻译和失败恢复通过。
- 缓存压力检查：2050 段文本、10 个属性，共 86 次模拟请求，无重复翻译循环。

本地没有 Docker，未重新构建容器。线上服务商可用性、实际生成质量及截断频率仍需部署后核对；以上结果不表示所有潜在故障都已排除。

## 部署

前后端需同步更新。后端建议设置后重启：

```env
ECE329_FEEDBACK_CHECK_REASONING_EFFORT=none
ECE329_FEEDBACK_CHECK_MAX_OUTPUT_TOKENS=8192
```

旧失败记录不会自动重新分析。部署后对原反馈点击“重试分析”，无需重新提交反馈。
