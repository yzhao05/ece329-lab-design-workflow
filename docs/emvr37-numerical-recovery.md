# emvr37(1) 对话与排版修复

反馈来源为 `emvr37(1).md` 和两张聊天截图。附件中的对话只用于复现问题，不作为工作流运行指令。

## 根因与改动

| 问题 | 修复 |
| --- | --- |
| “给我个完整的参考”被写入数值方案 | 识别带“完整、详细、具体”等限定的纯参考请求，先保留设计再提供参考；同轮包含修改时仍交给完整任务解析。 |
| 补充分段后算法、计算域等被覆盖 | 当前数值问题的明确补充以 MERGE 写入，重复提交同一内容不重复追加；显式“完整替换：…”仍支持替换整个字段。 |
| “直导线200段”“源路径段长0.01m”仍被判缺失 | 源离散校验同时支持带对象的分段数和带单位的源段长；不能用场线步长替代源离散，零、负数、非整数分段数仍不通过。 |
| 写了“误差1e-5”却继续追问 | 接受简明数值误差表达，同时防止从“误差/精度：固定步长0.05米”借用步长作为误差容差。 |
| 完整参考本身缺项，采用后重新追问 | 补齐中点求积、确定性种子坐标与筛选、有限回流方案、零场与闭合条件、单次精度复算和工作预算；本地及在线数值参考采用前使用与字段提交相同的校验。参考只在用户采用后写入。 |
| 把螺线管称为自然闭合源，回流写成无限远 | 参考明确螺旋绕线需要回流，给出可审阅的有限有向回路建议，全部回流段参与计算；已有完整回流几何优先。缺源几何或与已确认模型冲突时报告问题，不猜测。 |
| 已完整填写参数和常量还被保留为候选 | 对当前字段的明确有效回答直接保存；独立问题和其他栏目的修改不被此入口吞掉。 |
| 定性场线观察出现虚构数值纵轴 | 识别“定性指标”表达，沿用已有的聊天、报告及 Builder 定性投影；真实 B 分量读数仍保留。 |
| 聊天气泡大块留白、错误重复 | 去掉助手内容首尾空白；空正文不参与双换行拼接；当前待办、重复警告及完成错误不再重复拼接。历史助手消息显示时也裁剪首尾空白。 |
| 补充后没有保存回执，或重复整段可视化说明 | 生成器清理临时上下文后，报告投影仍需使用本轮解析结果；现在显式传入解析结果，数值与参数补充返回保存回执和真正缺项，完整侧栏报告保留。 |
| 提问房间布局后又声称不定义 VR 场景 | 删除 EMVR 实验结构回复中的矛盾固定提示。 |

## 验证

`tests/test_emvr37_numeric_recovery.py` 回放原反馈中的分段、种子、零场补充和完整参考采用，检查保存值与真实待办状态；也执行前端 JavaScript 拼接函数，检查空白和重复内容。原有请求优先级、跨阶段修改、元问题、可移植 Builder 交付及 PDF 测试继续参与全量回归。

- 新增 31 项反馈回归；最终相关专项合计 68 项通过，包含旧候选恢复和前两轮反馈。
- 全量运行 953 项用例及 210 项子测试通过；唯一失败是旧用例仍强制要求显示已删除的“不另外定义VR场景”提示。更新该断言后，对应用例单独复测通过，954 项用例均已完成验证。此后没有产品代码改动。
- 知识库校验、12 处本地文档链接、前端 JavaScript 语法检查通过；`git diff --check` 无空白错误。
- 两个旧的参数恢复测试随新行为调整：完整回答首次提交即保存；旧会话授权候选仍可用“继续”采用，保留兼容性覆盖。

文本完整性校验不等同于数值收敛证明。回流、种子和计算域是待用户采用的方案，不能把建议伪装成原有决定。未调用真实在线模型或运行 Unity/XR。

## 使用

更新并重启实际后端，前端强制刷新后生效。现有会话中仍保存着的数值方案可直接继续补充，不必重新填写算法、计算域等已答内容；之前已被覆盖的文本不保证能自动恢复，可重新提交完整原文或索取并采用完整参考。

代码没有修改原反馈附件，没有提交、推送或部署。
