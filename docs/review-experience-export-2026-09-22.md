# 经验导出功能复审

## 结论

复核最新导出改动及其与接口鉴权、证据展示、审阅草稿、生命周期、语言切换和工作流的连接。本轮未发现需要追加修复的功能错误，不为了审阅而改动已有业务逻辑。导出适用于 Guided、EMVR，以及待审阅、已启用、已停止；旧 rejected/disabled/deleted 状态仍可导出。

## 检查结果

- 每条经验顶部的导出按钮和原始 JSON 下载复用同一下载函数，脚本加载顺序及缓存版本已同步，页面引用无断联。
- 导出来自已鉴权接口返回的当前已加载记录；包括原始经验、关联反馈、可用上下文、状态、截图、分析、审阅及用量等已返回字段，不读取令牌输入框或未提交的 JSON/人工意见。
- 语言切换仅改变显示；导出内容不采用译文，不清除草稿。文件名带经验 ID 和版本，不冒充服务端后来更新的版本。
- 切换记录、刷新或退出后，旧顶部按钮不能再次导出旧记录；加载或提交期间不会触发额外导出。下载失败提供错误提示，不重试、不保存草稿。
- 下载为本地 Blob 操作，不调用模型，不触发反馈分析、审批或工作流推进；临时链接移除后释放对象 URL。没有新增自动重试循环。
- 后端反馈重试、双模式规则兼容及防重复执行守卫仍通过专项回归；没有放宽完整性、确认或权限检查。
