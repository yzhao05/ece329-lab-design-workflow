# EMVR Unity 位置示意图

工作台在 EMVR_DIRECT 显示单个卡片：上方总结当前已写入设计的对象、操作、观察内容和位置说明；下方以二维俯视方式显示有明确依据的组件局部位置关系。GUIDED_DESIGN 隐藏整个卡片。讲义依据继续承载公式与适用条件，原默认理论曲线和参数比例滑块已移除。

后端 `unity_layout_snapshot()` 是只读投影，每轮回复（含修订、撤销等）和 GET 设计快照携带 `unity_layout`，带 design_id/revision。使用 EMVR 当前结构化字段覆盖已确认 Brief，尊重字段 CLEAR，不读取旧对话、公式预设物体或 Builder 默认值；早期只读取语义分析中明确提及的对象。前端整体替换快照，不合并旧图；不同设计、Guided、缺少有效数据均清空图，刷新页面后等待后端当前快照。

绘图保持保守：明确的“组件 A 位于组件 B 右侧/左侧/前方/后方/中心”和对应英文关系可显示；明确的“在电流环圆心观察磁场”显示观察标记，不据此添加空间探针。操作与反馈只有明确因果连接（如 `→`、`使得`）才画箭头。每个图仅展示局部关系，图标不指定朝向或房间布局；没有单位坐标的内容不推算尺寸。冲突、否定、建议或无法安全解析的位置原文保留在文字区，图中留白并提示补充。自由描述未解析不等于设计内容被删除；用户可核对原文或进一步明确关系。此窗口不增加阶段门槛、不自动发送回答或推进流程。

卡片注明“方法示意，非实际仿真；位置与尺寸不按比例”。“补充位置说明”只将问题带入空的输入框，不覆盖用户草稿。所有标签按文本渲染，静态提示支持中英文，动态设计内容沿用现有翻译链路。

已有位置文字无法安全绘制时，保留原文并说明绘图限制，不把解析限制当作未回答的问题反复询问。左右/前后相反、中心与偏离中心、多个对象间的循环排序均检查冲突；同一对对象的左侧与前方可以同时成立。多个观察中心使用各自的标记，不强行合并。明确不需要固定观察点时，不绘制与其冲突的固定观察关系。

清除对象会同时清除相关位置和操作反馈箭头。超过 64 个对象或 256 条说明时，绘图区留白并保留文字，避免正则匹配组合过多。前端校验快照及嵌套数据结构，异常数据清空示意图，不中断对话渲染。

无需新环境变量，绘图投影本身不调用模型；动态英文内容沿用现有翻译通路。同步部署前后端并刷新静态资源。旧后端没有该投影时保持留白，不恢复默认曲线。
