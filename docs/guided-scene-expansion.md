# Guided 三图景扩容说明

每轮仍展示三个图景，候选总量由 138 增至 183（每个完整全课程周期 61 组）。新增 45 幅独立编写的图景，覆盖全部 32 组公式档案与 15 类范式，每类新增 3 幅。既有图景编号与公式绑定保留。

## 新增图景

| 实验范式 | 新增图景 |
| --- | --- |
| 正向现象展示 | 把磁矢势的地图卷成磁场；给一小块空间做电荷收支账；用一排时钟重放同一个正弦场 |
| 单参数扫描 | 放大一根电缆却保留内外比例；让电流刻度与储能刻度并排走；转动一扇让能流穿过的窗 |
| 多条件对照 | 让两个电容器遵守不同的约定；相同的磁感应强度配上不同的材料；两条一样快却不一样好接的线路 |
| 分量拆解与合成 | 让一个测点的合场拆成贡献账本；把电位移箭头拆成两层透明片；让不同载流子分别留下电流轨迹 |
| 空间搜索 | 用通量小盒子缩小隐藏电荷的范围；寻找电势为零却仍有方向的地方；在传播中的波上找同一拍 |
| 反向参数推断 | 从逐渐消退的电荷猜材料参数；隔着遮罩辨认导线里的电流；从幅度和相位的足迹辨认导电介质 |
| 预测—观察—解释 | 先猜磁力会不会把粒子越推越快；让线圈停在磁通很多的地方；在回波到来以前画出端口的下一步 |
| 边界条件比较 | 在材料交界处添一张自由电荷薄片；边框一样，里面却藏着不同的源；让波遇到阻抗相同而速度不同的邻居 |
| 极限情况与近似检查 | 从线圈中段走向理想模型的边缘；把几乎圆的轨迹放到放大镜下；给低损近似画一张误差地图 |
| 模型失效与反例 | 把藏在平均数里的不均匀找出来；给熟悉的谐波序列换掉一个端点；把为一个负载配好的接头交给另一个负载 |
| 瞬态过程 | 把同一段衰减放到两种时钟上；给充电电容器选两张不同的跨越面；等一束波离开后再结算能量 |
| 频率响应 | 在同一电流幅度背后寻找相位线索；保持磁通摆幅，只改变摇动的节奏；让四分之一波接头离开自己的设计频率 |
| 测量路径或观察方式比较 | 让两种仪表在同一对端点会合；让磁场的两种算法在同一测点碰面；只读波峰波谷会丢掉哪一半消息 |
| 设计与优化任务 | 用边界上的旋钮照顾一块目标区域；让一组电流既照顾中心又照顾旁边；给驻波里的器件选一个合适的位置 |
| 多方案比较 | 做出相同电容，却留下不同的内部场；不同绕法给出相同的中心磁场；让两块材料给出同样的电位移读数 |

## 抽样与引用规则

- 每幅新增图景沿用“物理画面—可以继续想—启发性延伸—组合提示”的写法，具体操作和研究问题与旧条目区分。
- 不把 32 × 15 全部机械展开。只有公式档案声明适用、且具备独立探索问题的组合才进入候选池。
- 优先抽当前主题，用户明确指定课程领域时只在该领域内抽取。新图景有独立画面，不再由关键词匹配套用旧模板。
- 剩余一两个图景会先展示；确实抽尽后才开始下一轮。换轮标记只重置相应领域的抽取记录，每组内部仍不重复。
- 选定图景后按稳定编号关联主公式、辅助公式及讲义页码；跨公式比较额外绑定辅助档案。
- EMVR 保持先确定公式、再动态生成方法的流程。
- 无需新增环境变量。更新部署或重启后端，启动时自动加载扩展目录；已有会话保留的旧图景编号仍可解析。
