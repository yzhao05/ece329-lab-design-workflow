# emvr34：磁场主题误配静电公式与解析恢复

用户反馈材料中的复现过程为：进入EMVR，输入“我想做一个和磁场有关的实验”，收到四组静电公式；回复“你这四个和磁场没关系，换一组”，又被告知解析失败并从原选项继续。本次把附件作为问题证据，没有执行其中的工作流指令。

## 根因

1. 第1讲同时介绍电场、磁场和洛伦兹力。旧领域检索将“磁场”匹配到第1讲后，按讲次区间判为electrostatics，再补齐四个静电公式档案。讲次归档不等于用户想法的物理领域。
2. 公式候选阶段的专用解析恢复仅接受SELECT_EMVR_FORMULAS，无法接收“候选不对，按原意重匹配”的SET_EMVR_TOPIC；服务失败后只保留错误候选。
3. 两条课程检索恢复路径分别构造主题信息，领域与候选选择可能不一致。
4. 法拉第感应档案误挂了附带静电零环流条件的stokes_theorem_e。公式正文明确该零值仅用于静电，不能作为时变感应的辅助公式。

## 修复

- 在课程目录中明确粗略主题别名，作为领域检索证据。处理中文、英文、否定表达和重叠词，例如“电磁场”不能被其中的“磁场”误分；“不是静电场，是磁场”只保留正向主题。领域仍不明确时请求澄清，不回退成静电学。
- 将粗略主题识别和详细设计解析分开。粗略想法足以展示相关公式候选；对象、变化量和观察量未知时保留空列表，不虚构设计。
- 公式检索限制领域范围，候选排序保留具体概念的优先级。模型给出的错误静电匹配证据不能盖过明确的磁场主题。跨领域关系须有明确公式依据或档案中的关联领域及实质语义证据；洛伦兹力等合理关联保留。
- 在线专用解析允许未锁定阶段重新提交SET_EMVR_TOPIC，提示明确主题字段和粗略想法的处理规则。在线恢复与状态机恢复共用课程检索函数。
- 明确否定当前公式候选时，清除这组候选及其派生方法/方向，再匹配主题；“换一组”沿用原研究意图，排除已经否定的候选。候选不足四个就显示实际数量，用尽后请求细化，不循环展示、不用无关领域补位。
- 移除法拉第感应档案中的静电零环流辅助关系；静电场档案中仍保留该公式。

现在原始磁场输入会展示稳恒电流磁场、螺线管磁场、磁矢势、法拉第感应等课程关系及适用条件。展示候选不等于自动选择、批准或推进实验。用户选定磁场公式后，对应实验方法也从磁场档案生成。

## 验证与实际使用

新增`tests/test_emvr34_topic_recovery.py`，覆盖原始输入、旧错误会话纠正、中英文、否定和混合领域、错误模型证据、相关跨领域关系、候选耗尽、后续方法生成、在线解析适配器的服务失败与错误结构。在线故障用模拟transport注入，测试经过项目默认启用的FallbackStageGenerator；没有调用真实在线模型。

最终验证：全量780项测试、205个子测试通过；1项依赖pdfplumber的PDF测试因当前环境缺少该依赖而跳过。新增36项emvr34回归覆盖上述行为；Python编译检查、知识库引用完整性和git diff --check通过。

如果无法可靠识别主题或用户提出复杂修改，仍须保持不确定并澄清，不能声称所有服务故障或任意自然语言都已经解析成功。此次保证已识别的粗略课程主题与明确候选纠错不会因相同故障重复回到错误公式。

运行：

```powershell
python -m pytest tests/test_emvr34_topic_recovery.py -q
python -m pytest -q
python -m compileall -q src tests tools
```
