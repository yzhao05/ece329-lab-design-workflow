# emvr37 项目复核与 Unity 交付检查

审阅范围包括本轮尚未提交的 emvr37 修改，以及请求路由、字段保存、课程引用投影、阶段恢复、Builder 校验与 PDF、前端和测试。保留此前修改；没有修改本机 BuilderPack 的受保护资源，没有提交、推送或部署。

## 发现与修复

| 问题 | 修复 |
| --- | --- |
| 数值补充直接拼接，旧步长、步数或分段数仍留在当前方案 | 对明确的标量赋值作局部替换，保留其他几何、算法、域及说明；主计算和验收复算参数分开处理。 |
| 曾经提交过某个数值后，改回该值被幂等缓存吞掉 | 数值合并依据当前状态计算，不因历史签名出现过就忽略有效恢复；重复提交相同内容仍不重复追加。 |
| 有效分段数掩盖同一方案中的负分段数；负数或步长冒充误差容差 | 检查源离散值的有限性与正值，误差容差不能从步长、步数或负数借值。 |
| 对话拒绝缺容差，直接 Builder 输入校验却允许导出 | 共享数值完整性检查；源公式的显式计算表达式也可识别，不要求重复书写定律名称。 |
| 旧公式别名把已移除的静电公式重新带入磁场参考 | 统一读取当前规范选择，兼容旧字段但不合并过期选择；修改时同步已有别名。在线参考与导出都检查所选源模型与算法是否匹配。 |
| 清空讲义依据后，报告仍显示旧讲义 | 清空状态显式覆盖旧显示投影，不能靠空字典 update 保留旧引用。 |
| 数值参考重设排除半径，与固定输入矛盾 | 新参考沿用固定输入中的排除半径。未确定时才提出默认建议。 |
| 采用后的 PDF 仍写“以下是待确认建议”“采用后替换” | 采纳说明保留在只读参考对话中，写入契约的值只保留实施内容。 |
| 数值方案更新后，控制条件仍重复旧的“512 源段” | 控制条件显示引用最新数值契约，不再保存第二份显示用数值；原始用户记录仍保留。 |
| 不设置曲线但保留中心 B 读数，PDF 又暗示需要数值形态纵轴 | “无曲线”与“完全定性”分别判断；固定读数不意味着必须有纵轴。无可移动探针也不意味着删除固定采样读数。 |
| 已在盲重建子包中，却定位到主包 | 优先验证当前子包标记及固定目录位置；无效子包明确失败，不退回主包，不重复复制运行。 |
| 房间说明只列 Part 01，落后于本机 BuilderPack | 使用三种 Prefab、五个链接实例及冻结装配配方；加入完整照明、当前场景 GI、布局和可见性验收。 |

数值更新仅对可明确识别的标量赋值执行局部替换，不声称能理解任意自由文本或证明复杂公式一致性。完整替换仍需明确指令；对话中的提问、元问题与复合修改继续由原有请求优先级和回归保护。

## 从零构建交付

样例通过正式状态机完成“索取完整参考 -> 采用 -> 重新审阅默认实施契约 -> 完成 -> 导出”。输出为 `output/pdf/emvr37-builder-review.pdf`；它是闭合圆环磁场的合成审阅样例，不代表用户实际实验或真实 Builder Gate 批准。

已具备从包内空实验场景开始编写实现所需的设计与搭建说明：

- 本机包根定位、工作区恢复、锁定 Unity 版本与依赖、源引用清单。
- 已选公式、参数、固定几何、单位、源求积、种子位置、RK4 步长、零场与终止条件、一次精度复算。
- 对象与步骤、控件及桌面/XR 等效路径、Common 实际接口和领域适配职责。
- 程序集与文件布局、Editor 构建入口、对象注册与引用绑定、事件去重和旧计算取消。
- Capture/Restore/Reset、Initial 与操作后可见状态、域证据及完成条件。
- 完整房间 Part 01 x2、Part 02 x2、Part 03 x1，15 x 18 m，资源与配方只读。
- `Policies/emvr-room-assembly.json`、`Policies/emvr-room-lighting.json` 及完整 `RoomLighting.lighting`；当前场景 GI 生成与可见效果验收。

逐项核对了 14 个包内实际文件引用，以及 Common 的 TryStartLab、TryCompleteCurrentStep、TryCaptureSnapshot、TryRestoreSnapshot、TryResetObjects 签名。没有读取旧 Lab 实现，也未复制包外参考到 PDF。

这意味着 Builder 可以按交付开始实现，不能宣称 PDF 已自动构建了可运行项目。仍需要包内锁定的宿主与依赖、领域和适配代码、Unity 编译、Game View 与桌面/XR 验收。本轮没有调用在线模型、执行 Unity/XR，也没有完成全轨迹收敛实验。

默认实施契约升为 `builder-ui-flow-v7`，指纹绑定完整生成内容。旧会话需要审阅更新后的实施说明，不能沿用旧批准替新要求背书。

## 验证与复现

- 新增 `tests/test_emvr37_project_review.py`，共 19 项检查，覆盖上述状态、引用、数值、工作区与交付问题。
- 完整回归通过 973 项用例及 210 项子测试；随后对“无曲线但保留固定读数”的两项 PDF 字段说明作最后修正，专项 19 项再次通过。
- 最终 PDF 23 页；逐页渲染检查，另核对文本边界、无机器绝对路径、无父目录越界引用、无旧源分段值及未解决占位内容。
- 独立 CPU 检查采用参考中的源段长 0.01 m 和 0.005 m，分别离散为 315 和 629 段；z=0、0.5、1.0 m 共六个轴上磁场结果相对解析值的绝对误差均小于 1e-9 T。
- 生成内容、知识目录及前端语法检查不替代真实模型响应或 Unity 运行证据。

项目依赖安装后，在仓库根目录复现：

```bat
set PYTHONPATH=src
python -m tools.export_emvr37_review
```

生成的输入和数值结果在 `build/emvr37-review/`，PDF 在 `output/pdf/`。这些目录被 Git 忽略；推送后可重新生成。
