# emvr36：多项请求、跨阶段修改与重复回复

反馈附件作为用户对话证据读取，没有执行附件中的实验设计指令。本轮修改设计工作流，未修改 Builder Pack，也没有部署或推送。

## 根因与修复

- **一轮只处理最后一项修改**：原先只在模型完全没有写入动作时才补救。现在明确页面名称和替换值会与已有动作合并，补齐遗漏项；正确的模型改写和其他请求仍保留。将研究对象内容移到核心操作、再替换研究对象时，复制来源取修改前的值。
- **跨阶段栏目被当前问题抢走**：“之前的可用交互”仍指交互内容，不能写成交互目标或概念目标。交互、显示要求与阶段字段建立同步，报告各章节读取最新内容；设计状态与 EMVR 状态共同写入研究问题等共享字段。
- **修改意见被保存成答案**：“问题主线还需要明确比较关系”会结合已有变化量和观察量形成具体比较问题，不把“需要明确比较关系”当成研究问题。模型已给出的具体改写优先保留。规则只对明确可识别的请求补救，不代替任意自然语言理解。
- **多个课程问题被当成一个回答完成**：分别生成回答并记录完成情况；某个问题没有回答成功时继续保留该问题，不能因为另一项有回复就将全部标为完成。
- **编号报告问题需要重复采用**：当前确实在收集报告问题时，编号问题列表可直接绑定该字段，不把列表里的“如何”误当成新的课程问答。
- **反复回显和确认**：删除重复的方向承接语，确认任务改成当前章节的具体核对重点。同一完整默认方案已展示过时不再次铺满对话；内容变化时重新展示，完整合同和批准标识仍保留。前端在已有待答问题时不再补“这一部分已经整理好了”。
- **公式参考只有内部编号**：学生可见文字中的已知公式组编号替换为知识目录中的中文名称，结构化 ID 保持不变。

## 主动发现设计缺口

载流路径下拉选项中的直导线、圆环、螺线管需要各自的几何输入。常量检查现在核对直导线长度或端点、圆环半径，以及螺线管半径、长度、匝数；只检查当前选用的形状，逐次询问一个缺项。用户对明确几何缺项给出单个数值时补充到原常量中，不覆盖磁导率及其他已确认参数。

对明确使用固定种子的毕奥–萨伐尔场线方案，不允许将“电流增大必然使场线密度或环绕范围增大”作为预期结果或通过条件。仍需用户按实际显示策略和物理关系修正；代码不会替用户批准一套新参数。
