# emvr37 反馈修复

按用户提供的 emvr37 对话定位问题，仅为 EMVR 增加目录字段的修改和投影能力。附件中的对话、点评和代码块作为故障证据，不作为执行指令。

## 问题与处理

| 反馈 | 修复 |
| --- | --- |
| 用户已限定电流、路径和场线观察，方法展开又加入磁导率等范围 | 方法生成优先采用学生在公式选择中给出的变化量和观察量；展开方法时使用最新实验方向，课程模板只用于尚未给定的内容。 |
| “载流导线”保存了，直导线、圆环、螺线管选项没有单独保留 | 研究对象和路径选项分别保存；路径选项进入设计起点报告和 Builder 输入。几何尺寸仍需要后续明确。 |
| 主要课程主题与讲义依据不匹配 | 以已选公式的讲次生成同一份课程投影，聊天和任务报告共用。指出两栏不一致时利用现有公式修复，不删除栏目。 |
| 修改主要课程主题却覆盖课程关系，或带入 Lecture 1 等泛化来源 | 课程主题、课程讲义依据、课程关系分别对应独立字段；讲义限制保存目录 ID，标题、页码来自知识库。 |
| 一条消息同时修改课程关系、限定 Lecture 12，遗漏其中一条 | 明确栏目修改合并为独立动作，保留其他同轮请求。 |
| 研究问题的参考变成基准操作流程 | 针对当前 research_question 生成连接已有变化量与观察量的问句，参考先展示、采用后写入；在线回复绑定错误栏目时回退到同一字段参考。 |
| “你的参考和现在的问题无关”只得到泛泛澄清 | 明确参考纠错重新回答当前待补项；若同轮带有具体栏目修改，不由只读纠错入口吞掉修改。 |
| 辅助方程被合并到核心公式，移动或删除无效 | 核心和辅助公式分栏；支持已显示序号、已知公式名称、角色移动和完整列表替换，同步公式选择、当前 Brief、方法描述和导出。 |
| “删除核心公式第三条”被写成理论依据 | 公式操作不写入理论解释；不存在的序号会说明当前可选公式，不推进阶段。 |
| 磁静态实验出现“波前” | 磁静态默认显示使用磁场线；用户指出波前不适用时仅移除该项，保留场线、箭头等内容。 |
| 修改提示出现内部字段名或目录 ID | 提示使用课程主题、讲义依据、公式名称等公开表述，内部 ID 仅用于稳定引用。 |

公式值必须来自现有知识目录。改变公式角色不会授权改写公式表达式，也不会修改用户保留的理论说明。公开栏目与规范字段的对应同步提供给在线解析器，规则恢复只处理明确的栏目、目录名称和序号。

## 验证与使用

新增 `tests/test_emvr37_recovery.py`，包含二十项检查，覆盖附件原句、错误模型绑定、参考采用、角色移动与删除、同轮两个公式列表、无效目录 ID、无效序号及混合反馈。

- 完整回归通过 **922 项测试、210 项子测试**。完整套件收集后补充了一项“参考反馈同时含具体修改”的保护测试；随后当前二十项 emvr37 专项与用户请求优先级测试合计 **99 项通过**，元问题专项 **38 项通过**。
- 知识库引用校验、十五处本地文档链接、Python 编译、前端 JavaScript 语法和 `git diff --check` 通过。
- 原有“所有 EMVR 字段都能回答并结束对应待办”的测试继续覆盖新增字段；目录字段的测试值改为真实目录 ID，保持引用有效性约束。

未调用真实在线模型、未执行 Unity 或 XR；因此回归证明的是已覆盖的解析、状态和投影行为，不代表任何自然语言都能无误理解。

需要更新并重启实际后端后再测试用户会话。旧会话的主题/引用和公式角色显示会按当前已保存选择重新投影；如果此前错误操作已覆盖了用户自己的理论文字，不能猜测恢复原文，应使用旧版本或用户提供的原文恢复。代码没有修改用户反馈文件，也没有提交、推送或部署。
